# NORTHCAT Knowledge Base 🧠

Организованная база знаний, идей и задач для проекта NORTHCAT. Помогает структурировать информацию и избежать выгорания через четкие приоритеты и фокус.

## 🗂️ Структура

### `/brain/` - Сырой мозг
- `ideas.md` - быстрые идеи, без фильтра (скидываем всё сюда)
- `questions.md` - нерешённые вопросы
- `connections.md` - связи между идеями и проектами

### `/tasks/` - Организованные задачи
- `current-sprint.md` - текущая неделя (MAX 5 задач)
- `priorities.md` - матрица важность × срочность
- `backlog.md` - отфильтрованный бэклог (не весь салат)

### `/docs/` - Архив знаний
- `domains/` - знания по доменам (дизайн, API, DevOps, TG-bot...)
- `decisions/` - архитектурные решения
- `learnings/` - уроки, интересные находки

### `/ai-agents/` - AI помощники
- `organizer.md` - инструкции для Claude как project manager
- `patterns.md` - шаблоны задач, чек-листы

### `/templates/` - Шаблоны
- Быстрые стартеры для новых задач, идей, документов

## 🚀 Быстрый старт

### Если срочная идея - скидываешь в `/brain/ideas.md`
```markdown
## [Идея] Название
- Описание в 1 строку
- Почему важно
- Связано с: (если есть)
```

### Если нужно организовать спринт
1. Чистишь `/tasks/current-sprint.md`
2. Выбираешь из бэклога MAX 5 задач по приоритету
3. Копируешь в спринт

### Если теряешь фокус
Спроси Claude: **"/organize-knowledge"** или **"Что мне делать дальше?"**

## 🤖 AI Команды

- **"Помощь с приоритизацией"** → Claude анализирует матрицу
- **"Что дальше?"** → Claude рекомендует следующую задачу
- **"Организуй ideas.md"** → Claude структурирует сырые идеи в задачи
- **"Покажи прогресс"** → Claude анализирует completed.md

## ⚡ Правила фокуса

1. **Спринт** - только 3-5 задач на неделю, не больше
2. **Идеи** - пока не додумал идею, её в `ideas.md`
3. **Приоритеты** - используй матрицу, не интуицию
4. **Отключи потоки** - работай над спринтом, остальное = бэклог

## 📊 Status Tracker

Где смотреть статус:
- **Текущие задачи**: `tasks/current-sprint.md`
- **Что прошлись**: `tasks/completed.md`
- **Идеи на горизонте**: `brain/ideas.md`
