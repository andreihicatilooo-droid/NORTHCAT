# 🎯 Матрица приоритизации (Важность × Срочность)

Используй эту матрицу когда нужно выбрать что делать. Это спасает от "разбегания рук".

```
                    СРОЧНО
                      ↑
                  ┌───────────┐
        ВАЖНО  ┌─ │  P1  │ P2 │ ─┐
              │   │(ДЕЛАЙ!(HIGH) │
              │   │      │     │  │
              │   ├─────────────┤  │
              │   │ P3   │ P4   │  │
              │   │      │     │  │
        НЕ    │   └─────────────┘  │
        ВАЖНО └─────────────────────┘
                  НЕ СРОЧНО → СРОЧНО
```

## 📌 Легенда

### P1 - КРИТИЧНО (ВАЖНО + СРОЧНО)
**Делай ПЕРВЫМ.** Это блокирует остальное или есть жесткий deadline.

Примеры:
- Дизайн сфинкса (deadline 25.06, нужен для website)
- Database schema (нужна для API)
- Критические баги в production

### P2 - ВЫСОКИЙ ПРИОРИТЕТ (ВАЖНО, но не срочно)
**Делай после P1.** Это важно для проекта, но есть время.

Примеры:
- Website frontend (важно, но можно сделать на неделю позже)
- TG-Bot MVP (критично, но есть запас времени)
- Documentation (важно архивировать знания)

### P3 - СРЕДНИЙ (не очень важно, может быть срочно)
**Делай если есть время и нет P1/P2.**

Примеры:
- Оптимизация кода
- UI улучшения
- Дополнительные команды в боте

### P4 - НИЗКИЙ (не важно и не срочно)
**Делай в последнюю очередь, или забей.**

Примеры:
- Nice-to-have фичи
- Теоретические улучшения
- Идеи на горизонте (год спустя)

---

## 📊 Как использовать

### Когда выбираешь задачу на спринт:

```
1. Посмотри в backlog.md
2. Выбери верхние P1 и P2 (макс 5 всего)
3. Положи в current-sprint.md
4. Работай сверху вниз (P1 → P2 → остальное)
```

### Когда теряешь фокус:

```
Спроси Claude:
"Какой приоритет у [задача]?"
"Что сейчас P1?"
"Могу ли я отложить [задача]?"
```

---

## 🔄 Пересчет приоритетов

**Раз в неделю (в пятницу)** проверь:
- [ ] Есть ли новые P1 задачи?
- [ ] Что изменилось в deadlines?
- [ ] Может какая-то задача стала менее важной?

Обновляй приоритеты в backlog.md если нужно.

---

## ❌ Типичные ошибки

| Ошибка | Результат | Решение |
|--------|-----------|---------|
| Все задачи P1 | Все одинаково срочно = паника | Выбери максимум 3-4 реальных P1 |
| P2 блокирует P1 | Работаешь на неправильном | Переделай приоритеты |
| Задача не в матрице | Не знаешь когда её делать | Добавь в backlog с приоритетом |
| Спринт переполнен | Не доделываешь ничего | Максимум 5 задач на спринт |

## 💡 Совет от Claude

Если не знаешь приоритет = спроси себя:
- **Важно ли для бизнеса?** → P1/P2
- **Есть ли жесткий deadline?** → P1
- **Это блокирует другое?** → повысь приоритет
- **Это nice-to-have?** → P3/P4
