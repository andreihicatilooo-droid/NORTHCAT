# 💭 Сырые идеи

Быстрый ввод идей БЕЗ фильтра. Потом Claude поможет структурировать в задачи.

## [Идея] Название
- **Описание**: одна строка что это
- **Почему**: почему это важно/интересно
- **Связи**: с какими проектами/идеями связано

---

## Примеры для удаления:

### [Идея] Система горячих клавиш для управления приоритетами
- **Описание**: быстрые сочетания клавиш для перемещения задач в матрицу
- **Почему**: экономит время при переоценке приоритетов
- **Связи**: AI-агенты, улучшение UX

### [Идея] Экспорт KB в PDF для офлайн просмотра
- **Описание**: один клик = PDF со всеми docs и текущим спринтом
- **Почему**: удобно иметь физический список на столе
- **Связи**: интеграции, документирование

### [Идея] Интеграция с Telegram для уведомлений о новых идеях
- **Описание**: кидаю идею в бот → она автоматом в ideas.md
- **Почему**: не отвлекаясь от мобильного, сохраняю идею
- **Связи**: TG-bot, автоматизация

---

## 🎯 Как использовать

1. **Срочная идея?** Кидаешь сюда сразу (даже наполовину готовая)
2. **Обдумал?** Добавляешь описание и почему важно
3. **Claude организует** → превращает в задачу в бэклог
4. **Раз в неделю** → чистишь хлам и archivo done
