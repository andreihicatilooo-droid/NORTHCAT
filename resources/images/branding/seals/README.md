# NORTHCAT Seals & Emblems

Круговые печати и магические эмблемы NORTHCAT.

## 🔮 Seal Designs

### Circular Seal (Круговая печать)
**Дизайн**: Sphinx cat (кот сфинкс) с открытым третьим глазом в центре пентаграммы

**Элементы**:
- Центр: магический символ в лбу кота
- Кольцо вокруг: текст "NORTHCAT" (Blackletter)
- Внешний круг: текст "СЕВЕРНЫЙ КОТ" + "Тату студия" (кириллица)
- Углы: магические символы (песочные часы, руна)
- Цвета: Hot Pink (#f4587e) на Dark Green-Black (#0c120e)

### Magic Symbols
- ⌛ Песочные часы (время, вечность)
- 🔮 Магическая руна (сила, магия)
- ♦️ Пентаграмма (защита, баланс)
