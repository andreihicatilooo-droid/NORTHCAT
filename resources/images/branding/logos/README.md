# NORTHCAT Logo Variations

Варианты логотипа NORTHCAT в различных формах и размерах.

## 📐 Logo Versions

### Horizontal Layouts (Горизонтальные)
- **northcat-landscape-v1.png** - Основной горизонтальный вариант
  - Размер: 1920x1080
  - Использование: веб-сайт, баннеры, печать
  - Цвета: Hot Pink (#f4587e) + Dark Green-Black (#0c120e)

- **northcat-landscape-v2.png** - Альтернативный вариант
  - Размер: 1920x1080
  - Использование: социальные сети, меркендайз

- **northcat-landscape-v3.png** - Компактный вариант
  - Размер: 1920x1080
  - Использование: мобильные, header сайта

### Circular/Seal (Круговые печати)
- **northcat-seal-v1.png** - Полная круговая печать
  - Размер: 1080x1080
  - Использование: эмблема, логотип профиля
  - Элементы: пентаграмма, магические символы, текст по кругу

- **northcat-seal-v2.png** - Альтернативный вариант печати
  - Размер: 1080x1080
  - Использование: меркендайз, печать

## 🎨 Design Details

Все логотипы разработаны **Dark Voio Studio**
