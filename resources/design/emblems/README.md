# NORTHCAT Emblems & Seals

Интерактивные дизайны эмблем NORTHCAT (логотипы-эмблемы).

## Содержимое

### `northcat-emblem.html` (1.4MB)
- Интерактивная HTML эмблема NORTHCAT
- Содержит полный дизайн с SVG/Canvas анимацией
- Может использоваться как портал или интерактивный элемент
- Совместима с браузерами (Chrome, Firefox, Safari)

## Использование

### В Website
```html
<!-- Встроить в iframe -->
<iframe src="/resources/design/emblems/northcat-emblem.html" width="800" height="800"></iframe>

<!-- Или открыть в отдельном окне -->
<a href="/resources/design/emblems/northcat-emblem.html" target="_blank">Открыть эмблему</a>
```

### В Canva
- Скачайте как изображение для использования в дизайне
- Используйте скриншот для Canva проектов

### На Сервере
- Разместите в папке `/public/` для прямого доступа
- Используйте для SEO-элементов (logo schema)
