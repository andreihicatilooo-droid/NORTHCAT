# 🤖 AI Management Guide - Управление проектом с Claude AI

Гайд для эффективного использования Claude как project manager assistant для NORTHCAT.

---

## 📋 Файлы для управления

| Файл | Назначение | Обновление |
|------|-----------|-----------|
| **PROJECT_MAP.md** | Большая картина, приоритеты, дедлайны | Раз в месяц |
| **INITIAL_TASKS.md** | Полный список всех задач по направлениям | Каждый спринт |
| **BACKLOG.md** | Упорядоченный список для работы | Еженедельно |
| **IDEAS.md** | Сбор новых идей | По мере появления |

## 💬 Как общаться с Claude

### Команда 1: "Что мне делать дальше?"

```
Вопрос:
"Посмотри на BACKLOG.md и скажи, какую P0 задачу мне начать?"

Claude ответит:
- Проанализирует приоритеты
- Предложит текущую задачу
- Подскажет зависимости
- Даст estimate по времени
```

### Команда 2: "Помоги мне план спринта"

```
Вопрос:
"Давай спланируем спринт на 2 недели. Сколько задач я могу сделать?"

Claude поможет:
- Оценить твою скорость (velocity)
- Выбрать P0 и P1 задачи
- Создать realistic timeline
- Определить зависимости
```

### Команда 3: "Я закончил X, что дальше?"

```
Вопрос:
"Я завершил website landing page. Какой next step?"

Claude подскажет:
- Проверит зависимости
- Предложит related tasks
- Обновит BACKLOG.md
- Даст рекомендацию по next step
```

### Команда 4: "Дай мне обзор прогресса"

```
Вопрос:
"Какой мой прогресс по всем направлениям? Где я отстаю?"

Claude создаст:
- Таблицу прогресса по направлениям
- Анализ завершенных vs плановых задач
- Рекомендации где ускориться
- Риски просрочки
```

### Команда 5: "Дай мне quick win"

```
Вопрос:
"У меня есть 1 час. Какую quick P1 задачу я могу сделать?"

Claude предложит:
- Задачи на 30-60 минут
- Не требующие предварительной подготовки
- Дающие видимый результат
- Открывающие путь к P0 задачам
```

### Команда 6: "Перепланируй из-за Y"

```
Вопрос:
"Я потратил 2 дня на X и задержусь. Как переорганизовать спринт?"

Claude поможет:
- Переоценить оставшееся время
- Выбрать что drop/postpone
- Переорганизовать приоритеты
- Обновить дедлайны
```

### Команда 7: "Какие зависимости у X?"

```
Вопрос:
"Могу ли я начать разработку website без database setup?"

Claude ответит:
- Какие task blockers
- Что можно сделать параллельно
- Что нужно сделать сначала
- Рекомендует order of operations
```

### Команда 8: "Валидируй мой обзор"

```
Вопрос:
"Я сделал review IDEAS.md и выбрал эти 5 идей для BACKLOG. Звучит правильно?"

Claude проверит:
- Alignment с PROJECT_MAP
- Логичность приоритизации
- Balanced ли распределение по направлениям
- Есть ли важное что забыл
```

## 🎯 Weekly Ritual (каждый четверг)

### Шаг 1: Sprint Review (30 мин)
```
Вопрос Claude:
"Давай сделаем sprint review. Что я завершил за неделю?"

Ожидаемые действия:
1. Посмотрит INITIAL_TASKS.md
2. Подсчитает completed ✅ задачи
3. Оценит прогресс (% complete)
4. Определит заблокированные задачи
```

### Шаг 2: Ideas Review (20 мин)
```
Вопрос Claude:
"Давай просмотрим IDEAS.md. Какие идеи стоит переместить в BACKLOG?"

Ожидаемые действия:
1. Прочитает IDEAS.md
2. Оценит каждую идею (Impact/Effort)
3. Предложит 3-5 для next спринта
4. Поможет их структурировать
```

### Шаг 3: Backlog Planning (30 мин)
```
Вопрос Claude:
"Составь мне план на следующий спринт на основе Backlog"

Ожидаемые действия:
1. Выберет P0 задачи
2. Добавит P1 если есть время
3. Проверит зависимости
4. Установит дедлайны (dueString)
5. Выведет список для Todoist
```

### Шаг 4: Project Memory Update (10 мин)
```
Вопрос Claude:
"Помоги мне обновить PROJECT_MEMORY.md с текущим статусом"

Ожидаемые действия:
1. Составит обзор прогресса
2. Обновит текущие статусы
3. Укажет что в фокусе
4. Отметит блокеры
```

## 📊 Monthly Ritual (в конце месяца)

### Полный обзор и переплан

```
Вопрос Claude:
"Давай сделаем месячный обзор и переплан на следующий месяц"

Ожидаемые результаты:
1. Обзор по всем 6 направлениям
   - Завершено за месяц
   - На что потратил основную часть времени
   - Что отстаёт

2. Анализ скорости (velocity)
   - Сколько задач обычно беру
   - Сколько реально завершаю
   - % completion rate

3. Риск анализ
   - Что под угрозой просрочки
   - Зависимости которые блокируют
   - Нужны ли ресурсы

4. Переплан на следующий месяц
   - P0 задачи
   - P1 задачи
   - Allocation по направлениям
```

## 🔄 Integration with Todoist

### Как делегировать задачи в Todoist

```
Вопрос Claude:
"Дай мне Todoist команды для 5 tasks из BACKLOG"

Claude вернет:
- Название задачи
- Описание
- Priority (p1-p4)
- Due date (dueString: "завтра", "25 июня", etc.)
- Duration estimate (2h, 30m, etc.)
- Project name (Дизайн NORTHCAT или TG-бот / Агент)

Ты просто копируешь в Todoist!
```

## 🚀 Advanced: Delegation Patterns

### Pattern 1: "Спроектируй мне"

```
Вопрос:
"Спроектируй мне архитектуру для TG-Bot Claude integration"

Claude предоставит:
- Диаграмма компонентов
- Sequence diagram
- API contracts
- Error handling strategy
- Security considerations
```

### Pattern 2: "Валидируй мой подход"

```
Вопрос:
"Я хочу использовать Redis для session management. Хорошая идея?"

Claude:
- Проанализирует pros/cons
- Предложит альтернативы
- Даст рекомендацию
- Укажет на потенциальные issues
```

### Pattern 3: "Помоги с decision making"

```
Вопрос:
"Должен ли я использовать PostgreSQL или MongoDB?"

Claude:
- Сравнит для NORTHCAT use case
- Укажет pros/cons для каждого
- Даст рекомендацию based on requirements
- Поможет составить ADR (Architecture Decision Record)
```

### Pattern 4: "Структурируй мою идею"

```
Вопрос:
"У меня есть идея про AI tattoo designer. Помоги разобраться"

Claude:
- Уточнит требования
- Разложит на компоненты
- Определит сложность
- Предложит phased approach
- Оценит effort и impact
```

## 🎓 Best Practices

### DO ✅
- Читай PROJECT_MAP.md перед планированием
- Обновляй INITIAL_TASKS.md progress регулярно
- Фиксируй идеи в IDEAS.md сразу же
- Делай sprint reviews каждую неделю
- Обсуждай big decisions с Claude перед реализацией
- Веди честное время estimation

### DON'T ❌
- Не планируй слишком много на спринт
- Не игнорируй P0 задачи ради P1
- Не добавляй задачи без из в INITIAL_TASKS.md
- Не забывай обновлять BACKLOG.md
- Не работай без плана (каждый день должен быть clear focus)
- Не переоценивай свои abilities
