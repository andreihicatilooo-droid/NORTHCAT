# Система планирования NORTHCAT

Единая система: дорожная карта → идеи → задачи → шаги → баги → недочёты.

## Типы записей

| Тип | Префикс | Папка |
|-----|---------|-------|
| Идея | `IDEA-NNN` | `ideas/` |
| Задача | `TASK-NNN` | `tasks/` |
| Баг | `BUG-NNN` | `bugs/` |
| Техдолг | `DEBT-NNN` | `debt/` |
| Пробел | `GAP-NNN` | `debt/` |

## Шкала оценок (1–5)

| Код | Метрика |
|-----|---------|
| **U** | Своевременность |
| **I** | Польза |
| **R** | Опасность (если не сделать) |
| **C** | Сложность |
| **D** | Зависимости (сколько ждут) |

**Priority** = `(U×3 + I×3 + R×2 + D×2) − (C×1.5)`

## Workflow

```
IDEA → triage → TASK → steps → done
BUG  → triage → fix  → verify → done
```

## Файлы

- `ROADMAP.md` — фазы и вехи (ссылки на TASK)
- `INDEX.md` — реестр активных записей
- `PROPOSALS.md` — **предложения задач**, порядок работ, формулировки Todoist
- `templates/` — шаблоны task, bug, debt, gap, idea

## Связь с Todoist

- Задача: `TASK-042 Название`
- Шаг: `TASK-042/S3 Название`
- Дедлайн: поле `due` → `dueString` в Todoist
