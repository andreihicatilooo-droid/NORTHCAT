## 📝 Как использовать этот файл

**Процесс:**
1. Идея приходит в голову → Запиши сюда в нужную секцию
2. Идея окрепла → Переведи в `INITIAL_TASKS.md` как задача
3. Готово к работе → Создай в Todoist
4. Завершено → Удали отсюда, добавь в `COMPLETED.md`

**Примеры форматов:**
- `[ ] Описание идеи` - новая идея
- `[x] Описание идеи` - реализовано
- `[~] Описание идеи` - в процессе

**Регулярно (раз в неделю):**
- Просмотри IDEAS.md
- Выбери 3-5 идей для следующей недели
- Переведи их в INITIAL_TASKS.md
- Создай задачи в Todoist
